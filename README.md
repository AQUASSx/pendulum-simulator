# Pendulum Simulator

Интерактивный симулятор маятника в браузере: простой, физический и двойной (хаотический) маятник с графиками, пресетами и экспортом данных.

🔗 **Демо:** https://aquassx.github.io/pendulum-simulator/

## Возможности
- Три режима: простой, физический, двойной маятник
- Графики угла, фазовой траектории и сечения Пуанкаре
- Экспорт данных в CSV и графика в PNG
- Готовые пресеты (малые/большие колебания, критическое затухание, невесомость, хаос)
- Переключение RU/EN и светлая/тёмная тема
- Формулы через MathJax

## Технологии
Чистый HTML/CSS/JavaScript, без сборки и зависимостей. Шрифт JetBrains Mono и MathJax подключены с CDN.

## Запуск локально
Просто открой `index.html` в браузере — сервер не нужен.
